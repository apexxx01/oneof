How to use this page

Try the pill, post nothing

  1. Install the OneOf extension: download the .zip, unzip it, open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the unzipped folder. Then open its side panel (toolbar icon). It needs desktop Chrome with Gemini Nano.
  2. In the panel, pick Use the demo history.
  3. Type in the reply box and pause. The pill shows the crowd you’d be in if you posted.
  4. Click the pill for the details, then Blur it on this device.
What this page does

Nothing leaves this page. It has no network or model code, and “Post reply” only says it didn’t post. The extension reads the box you type in, on your device, with Gemini Nano.
